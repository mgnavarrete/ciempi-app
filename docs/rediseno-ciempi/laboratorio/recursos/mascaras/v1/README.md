# Mascaras · v1 experimental

Estado: **En revisión artística**, no aprobado para producción. [Evaluación, comparaciones y pruebas](../../../../revisiones/B06-B07-B08-produccion-v1/REVISION.md).

SVG editables con viewBox `0 0 1000 650`, degradados y referencias locales prefijadas por ID. Las definiciones están en `defs`; `data-plane="back"` contiene la parte posterior; `front` contiene parte visible. El catálogo identifica versión, relación histórica, categoría y comportamiento facial. No hay PNG incrustados.

Gorros y máscaras usan cabeza, excluyen pelo nuevo y son mutuamente excluyentes. Antifaces B07 conservan ojos reales mediante aberturas; máscaras completas ocultan rostro y antenas. Las máscaras excluyen lentes y cicatriz. Capas usan espalda, excluyen mochilas y admiten bufanda por encima de su sujeción.

Fuente reproducible: `revisiones/B06-B07-B08-produccion-v1/crear-recursos.py`. No volver a ejecutar el generador sobre v1 para una revisión posterior: crear nueva versión y conservar esta evidencia. Originales del prototipo permanecen disponibles en el catálogo histórico.
