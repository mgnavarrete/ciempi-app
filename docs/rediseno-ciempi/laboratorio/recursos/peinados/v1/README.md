# B05 · peinados v1

Once construcciones SVG editables, **En revisión artística**. El catálogo declara IDs estables, referencia anterior cuando existe y exclusiones de gorros. La cabeza original no se reemplaza.

`data-plane="back"` contiene caída larga/coletas/trenza/moños detrás de cabeza; `front` contiene nacimiento, flequillo, sombras y mechones cercanos. Los recortes por plano impiden que luces o líneas del pelo pasen sobre la piel. Se conservan las antenas originales y sus puntas visibles.

Elegir peinado cambia el gorro a `cabeza-nada`. Elegir después un gorro, máscara o peinado histórico oculta el pelo nuevo sin borrar su selección. Volver a Sin gorro lo recupera. Esta exclusión conserva la restricción vigente; no se afirma compatibilidad universal con sombreros. Los lentes funcionan en un espacio independiente y se dibujan delante del pelo, evitando monturas escondidas.

La solicitud IA de pelo fue rechazada por el servicio; estos recursos son construcción vectorial intencional a partir de referencias originales, no imágenes IA vectorizadas. [Proceso y límite](../../../../revisiones/B04-B05-produccion-v1/ia/PROCESO.md).
