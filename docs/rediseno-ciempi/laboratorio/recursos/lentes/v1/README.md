# B04 · lentes y detalle facial v1

Doce maestros SVG de monturas, dos acabados adicionales sobre geometría compartida y una cicatriz independiente. **En revisión artística**. Catálogo: `catalogo.json`; detalle: `detalles.json`. No hay PNG incrustados.

Planos `data-plane="back"` / `front`, viewBox `0 0 1000 650`, IDs prefijados por pieza. Las monturas usan anclajes de ojos (708,342) y (808,320), con escala de perspectiva .86 para el lente lejano. Los degradados, trazados, patillas, puentes y reflejos son editables. `variantes[].colores` modifica rellenos/stops por paleta sin copiar geometría.

Transparentes: Lector, Redondos, Corazones, Arcoíris, Aviador, Mariposa y Científico. Opacos: Estrellas, Llamas, Visor, Deportivo y Sol. La ocultación sucede en el adaptador del laboratorio; los originales B03 no cambian. La cicatriz se equipa desde Detalles faciales y no obliga a llevar una montura. Las máscaras excluyen lentes/detalles; el selector conserva la elección para recuperarla.
